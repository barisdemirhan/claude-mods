# Security

This repository holds only the list of mods. A security problem in a mod belongs to that mod's own repository: open its **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for it.

- [claude-ambient](https://github.com/barisdemirhan/claude-ambient/security)
- [claude-dino](https://github.com/barisdemirhan/claude-dino/security)
- [claude-pomodoro](https://github.com/barisdemirhan/claude-pomodoro/security)
- [claude-tycoon](https://github.com/barisdemirhan/claude-tycoon/security)

For a problem with the list itself, report it here the same way.
